# Over-segmentation is fine IF domains are genuine; cross-domain composition is a FEATURE — SETTLED [USER]

**Decision:** Self-assembly may open hundreds of fine domains for a few true processes — that is
acceptable. Retrieval is a single GLOBAL kNN with no src filter; segments are a provenance overlay for
EDITING, not a retrieval partition. Cross-domain interactions in generation/retrieval are OK and
EXPECTED — composition is a feature, not a bug to fix. Self-assembly itself is a hard requirement.
**Why:** over-segmentation is proven harmless — knowledge composes across segments (global beats siloed).
**Source:** `STATE.md §2` Design decisions; `CL_TESTBED.md` §C / composition.
