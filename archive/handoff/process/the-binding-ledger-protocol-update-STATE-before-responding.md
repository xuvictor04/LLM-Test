# The binding ledger protocol — update STATE.md BEFORE responding, every turn

The assistant MUST, every turn: update `STATE.md` before responding (add to §6 Changelog, edit any
section that changed); before ANY choice, check §2 (Decisions) and §5 (Config) and follow `[USER]`
calls without overriding; keep the Included / Not-included / Deferred accounting (§3) current.

`[USER]` = the user's explicit call (do not override). `[me]` = an assistant default (must be flagged).

**Source:** `STATE.md §3` (the protocol) — binding.
