# Multimodality — pluggable "avenues" (SENSES) — GOAL, not designed [USER, long-horizon]

> TERMINOLOGY [USER, confirmed]: an "avenue" = a **Sense** = a MODALITY / perceptual channel (input AND output). The
> system is ONE sense today — language (an LLM). Adding a modality = adding a sense: attach a mic → an audio sense; a
> camera → a vision sense. Senses integrate at the LOWEST tokenizer layer and are "discovered" when unknown/unusual input
> arrives, BEFORE the reconcile → understand stages. Each sense is a parallel channel running the population primitive at
> its own token grain into the shared signature space. (Sense = modality; NOT polysemy — see the knowledge-base direction.)

**What:** the ability to plug in and add more modalities ("avenues") beyond text — extending the system to new input/output
channels without re-architecting.
**Status:** a stated north-star goal (`../NORTH_STAR.md`). No design exists yet. Naturally aligned with the growability
invariant — the society/expert-population + provenance-tagged memory are, in principle, an extensible substrate for adding
avenues — but nothing multimodal has been built or specified.
