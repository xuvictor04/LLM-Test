# Genuineness = silhouette (not size); the "genuine" COUNT is arbitrary — performance is what matters — SETTLED [USER]

**Decision:** Domain genuineness is measured by silhouette (cohesion + separation − 1), not by cluster
size. But the number of "genuine" domains is just where the silhouette cutoff sits — a diagnostic, NOT
a capability metric. Judge the system by PERFORMANCE (does memory earn its keep; does editing stay
local), not by the genuine-count.
**Source:** `STATE.md §2` Design decisions; `CL_TESTBED.md` §C.
